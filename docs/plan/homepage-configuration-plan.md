## 1. Global definition

- **Slug:** `homepage`
- **Type:** Global (singleton — no list view, no slug routing)
- **Versions/drafts:** Yes — `versions: { drafts: { autosave: { interval: 100 } }, maxPerDoc: 50 }`. Rationale: the photographer must be able to preview edits before they go live without fear of accidentally publishing.
- **Live Preview URL:** `'/'` (homepage is always at root).

### Top-level flat fields (outside the `layout` block field)

The hero section (Section 1, node `6730:17313`) is the LCP-critical viewport. It must not be deletable or reorderable by the user accidentally removing the block. Therefore hero fields live flat on the Global, not inside `layout`.

| name | type | required | label (PL) | notes |
|---|---|---|---|---|
| `heroImage` | `upload` (relationTo: `'media'`) | true | Zdjęcie tła hero | `next/image priority`, size ~1366×640. `fetchPriority="high"`. |
| `heroHeading` | `text` | true | Nagłówek główny | The large italic heading: "Zdjęcia, przy których możesz odetchnąć…". Plain text — formatting (italic spans) are baked into the typography class, not CMS-controlled. |
| `heroSubheading` | `textarea` | false | Podtytuł / lead | 2–3 sentence description below the heading. No rich text — single block of plain text. |
| `heroPrimaryButtonLabel` | `text` | true | Etykieta przycisku głównego | Default: "Poznaj mnie bliżej" |
| `heroPrimaryButtonUrl` | `text` | true | Link przycisku głównego | Default: `/o-mnie`. Plain text URL (internal slug). Not a relationship to pages — OPTION A (text) vs OPTION B (relationship to pages). Recommend A for launch velocity; upgrade to relationship field later. |
| `heroSecondaryButtonLabel` | `text` | false | Etykieta przycisku drugiego | Default: "Zobacz moje kadry →" |
| `heroSecondaryButtonUrl` | `text` | false | Link przycisku drugiego | Default: `/galeria` |

**Why flat:** The hero image drives LCP. If the block is missing (e.g., someone deletes all blocks), the page would have no image at the top — a catastrophic visual failure and Core Web Vitals regression. Flat fields ensure the hero is always present and always rendered first.
